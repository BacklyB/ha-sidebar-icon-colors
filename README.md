# Sidebar Icon Colors for Home Assistant

[🇩🇪 Deutsche Version weiter unten](#deutsch)

Color the icons in the Home Assistant **sidebar** and in **dashboard view tabs**, configured with a card in the UI. No YAML per icon, no theme editing.

Styles per icon:

- **Single color**
- **Gradient** (two colors, diagonal)
- **4 quarters** (four colors, one per quarter)
- **Tiles** (four colors, one per tile; only for the dashboard icons `mdi:view-dashboard` and `mdi:view-dashboard-outline`)

Works for all regular sidebar entries (dashboards, add-ons, HACS, Energy, …) as well as **Settings** and **Notifications** at the bottom. Settings are stored in Home Assistant and apply to all users and devices. The card is shown in English or German depending on your Home Assistant language.

## Installation

> **Important:** the script has to be loaded as a **frontend module** (`extra_module_url`), not only as a dashboard resource. Dashboard resources are only loaded once a dashboard is opened, so after a reload the sidebar would stay uncolored until you click on a dashboard.

### Via HACS (custom repository)

1. HACS → ⋮ (top right) → **Custom repositories**
2. Repository: `https://github.com/BacklyB/ha-sidebar-icon-colors`, type: **Dashboard**
3. Install **Sidebar Icon Colors**
4. Add this to your `configuration.yaml`:
   ```yaml
   frontend:
     extra_module_url:
       - /hacsfiles/ha-sidebar-icon-colors/ha-sidebar-icon-colors.js
   ```
   If you already have a `frontend:` section (e.g. for themes), only add `extra_module_url` below it. `frontend:` must not appear twice.
5. Restart Home Assistant, then reload the browser with Ctrl+F5.

HACS also adds the file as a dashboard resource. That is harmless: the script detects when it is already running and starts only once.

### Manual

1. Download `ha-sidebar-icon-colors.js` from the [latest release](https://github.com/BacklyB/ha-sidebar-icon-colors/releases) and copy it to `/config/www/`.
2. Add this to your `configuration.yaml`:
   ```yaml
   frontend:
     extra_module_url:
       - /local/ha-sidebar-icon-colors.js
   ```
3. Restart Home Assistant, then reload the browser with Ctrl+F5.

## Usage

Add the editor card to any dashboard:

```yaml
type: custom:sidebar-icon-colors-card
```

- Tab **Sidebar**: pick a style and colors for each entry. You see a live preview; **Save** stores it for everyone.
- Tab **Dashboard tabs**: pick a dashboard, then color its view icons. Dashboards generated by a strategy (e.g. auto-generated ones) only show their tabs after you have opened them once in that browser.

Only administrators can save.

## Limitations

- The script works by reading and changing the structure of the Home Assistant frontend (element IDs and the sidebar layout). **A Home Assistant update can break it** at any time. If that happens, please open an issue with your Home Assistant version.
- Your profile picture at the bottom of the sidebar is a picture, not an icon, and cannot be colored.
- Tabs without an icon cannot be colored.
- In the companion app, a new frontend module may only show up after restarting the app or clearing the frontend cache.

# Sidebar Icon Colors für Home Assistant (Deutsch)

Färbt die Icons in der **Seitenleiste** und in den **Tabs von Dashboards** von Home Assistant ein. Eingestellt wird alles über eine Karte in der Oberfläche, ohne YAML pro Icon und ohne Theme-Bastelei.

Stile pro Icon:

- **Eine Farbe**
- **Farbverlauf** (zwei Farben, diagonal)
- **4 Viertel** (vier Farben, je eine pro Viertel)
- **Kacheln** (vier Farben, je eine pro Kachel; nur für die Dashboard-Icons `mdi:view-dashboard` und `mdi:view-dashboard-outline`)

Funktioniert für alle normalen Einträge der Seitenleiste (Dashboards, Add-ons, HACS, Energie …) und auch für **Einstellungen** und **Benachrichtigungen** ganz unten. Die Einstellungen werden in Home Assistant gespeichert und gelten für alle Benutzer und Geräte. Die Karte erscheint je nach Sprache von Home Assistant auf Deutsch oder Englisch.

## Installation

> **Wichtig:** Das Skript muss als **Frontend-Modul** (`extra_module_url`) geladen werden, nicht nur als Dashboard-Ressource. Dashboard-Ressourcen lädt Home Assistant erst, wenn ein Dashboard geöffnet wird. Nach einem Neuladen bliebe die Seitenleiste sonst so lange ungefärbt, bis man auf ein Dashboard klickt.

### Über HACS (benutzerdefiniertes Repository)

1. HACS → ⋮ (oben rechts) → **Benutzerdefinierte Repositories**
2. Repository: `https://github.com/BacklyB/ha-sidebar-icon-colors`, Typ: **Dashboard**
3. **Sidebar Icon Colors** installieren
4. In der `configuration.yaml` eintragen:
   ```yaml
   frontend:
     extra_module_url:
       - /hacsfiles/ha-sidebar-icon-colors/ha-sidebar-icon-colors.js
   ```
   Gibt es schon einen Abschnitt `frontend:` (z. B. für Themes), nur `extra_module_url` darunter ergänzen. `frontend:` darf nicht doppelt vorkommen.
5. Home Assistant neu starten, danach den Browser mit Strg+F5 neu laden.

HACS trägt die Datei zusätzlich als Dashboard-Ressource ein. Das schadet nicht: Das Skript erkennt, wenn es schon läuft, und startet nur einmal.

### Manuell

1. `ha-sidebar-icon-colors.js` aus dem [neuesten Release](https://github.com/BacklyB/ha-sidebar-icon-colors/releases) herunterladen und nach `/config/www/` kopieren.
2. In der `configuration.yaml` eintragen:
   ```yaml
   frontend:
     extra_module_url:
       - /local/ha-sidebar-icon-colors.js
   ```
3. Home Assistant neu starten, danach den Browser mit Strg+F5 neu laden.

## Benutzung

Die Editor-Karte in ein beliebiges Dashboard einfügen:

```yaml
type: custom:sidebar-icon-colors-card
```

- Reiter **Seitenleiste**: Für jeden Eintrag Stil und Farben wählen. Die Vorschau ist sofort sichtbar, **Speichern** übernimmt es für alle.
- Reiter **Dashboard-Tabs**: Dashboard auswählen und dann die Icons seiner Ansichten einfärben. Bei Dashboards, die eine Strategie erzeugt (z. B. automatisch generierte), erscheinen die Tabs erst, nachdem man das Dashboard in diesem Browser einmal geöffnet hat.

Speichern können nur Administratoren.

## Einschränkungen

- Das Skript liest und verändert den Aufbau des Home-Assistant-Frontends (Element-IDs und Aufbau der Seitenleiste). **Ein Update von Home Assistant kann es jederzeit kaputt machen.** Dann bitte ein Issue mit der Home-Assistant-Version anlegen.
- Das Profilbild ganz unten in der Seitenleiste ist ein Bild und kein Icon und lässt sich nicht einfärben.
- Tabs ohne Icon lassen sich nicht einfärben.
- In der Companion-App erscheint ein neues Frontend-Modul eventuell erst nach einem Neustart der App oder nach dem Leeren des Frontend-Caches.
